utils = functions being used in multiple scripts

mixin/ui = change the title and splashes
mixin/resourcepack = creating the resource pack
mixin/entity = on entity added

loader/converter = convert files like .tga to .png
loader/definitions = getting all objects such as render controllers and saving them to a hashmap
loader/resourcepack = loading all things that are required for the resourcepack

loader/molang/MolangParser= Central Molang interpreter. Reads Molang strings, handles operators/logic/assignments, and forwards entity and math expressions to the specialized parsers.
loader/molang/types/MolangEntityParser= Handles entity queries and per-entity Molang variables (v./t.).
loader/molang/types/MolangMathParser= Handles math.* functions and evaluates their arguments through MolangParser.

entities/on_spawn/EntityHandler = do things for the entity, like initizialize the entity
entities/on_spawn/EntityLoadHandler = when loading entity do things in entity handler
entities/on_spawn/EntitySpawnHandler = when spawning entity do things in entity handler

entities/EntityRegistry = create for each entity type a class with textures, rendercontrollers, etc.
entities/EntityResolver = resolves an entity's textures, geometries, render controllers, and scripts and returns the actual resources/data for the entity
